# NexoCEO Site

Landing page recriada em React + TypeScript + Vite a partir da referência visual fornecida.

## Rodar localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

## Estrutura principal

- `src/App.tsx`: conteúdo, componentes e interações da página.
- `src/styles.css`: layout, responsividade, cores, mockups e animações visuais.
- `vite.config.ts`: configuração do Vite.

A página é responsiva, possui navegação por âncoras, menu mobile, CTA de contato, cards de produtos, dashboard desenhado em HTML/CSS/SVG e alternância de depoimentos.
